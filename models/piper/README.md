# Piper voices

Gremlin speaks assistant replies with [Piper](https://github.com/rhasspy/piper),
fully on this machine. The web UI picks a voice under **Settings → Piper TTS →
Voice**; the choice is saved to `data/settings.json` (`piper_voice`).
